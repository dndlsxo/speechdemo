# 발표 암기 (SpeechMemo)

발표 원고를 붙여넣으면 휴대폰 음성으로 자연스럽게 읽어 주고, 외우기 연습과 음성 파일 저장까지 해 주는 안드로이드 앱.

## 기능
- **원고 정리**: 빈 줄 = 단락, 문장 부호 기준으로 문장 분리. 글머리 기호 제거, PDF처럼 중간에 끊긴 줄은 다시 이어 붙임.
- **재생 모드**: 연속 재생 / 문장마다 따라 말하기(말할 시간만큼 쉼) / 단락 3번씩 반복, 전체 반복, 속도 0.5–1.5x
- **가리기 연습**: 원문 → 30% → 60% → 첫 글자만 → 모두 가리기. 문장을 길게 누르면 잠깐 보기.
- **음성 파일 저장**: 위 세 모드 그대로 WAV 파일 생성 → `음악/SpeechMemo` 폴더. 음악 앱에서 반복 재생하면 화면 꺼도 계속 듣기.
- **목소리·엔진 선택**: 구글/삼성 TTS, 고음질 목소리 고르기
- 메모·카카오톡에서 **공유 → 발표 암기**로 바로 원고 추가

## 설치
1. 저장소의 **Releases → latest → SpeechMemo.apk** 를 휴대폰에서 받기 (또는 Actions 탭의 아티팩트)
2. "출처를 알 수 없는 앱 설치" 허용 후 설치
3. 더 자연스러운 목소리: Play 스토어에서 **Google 음성 인식 및 합성** 업데이트 → 앱 메뉴 "음성 데이터 설치·설정"에서 한국어 음성 받기 → "목소리 선택"에서 고음질 목소리 고르기

Android 10 이상.

## 빌드
`main`에 푸시하면 GitHub Actions가 자동으로 APK를 빌드합니다 (Gradle 8.10.2, AGP 8.7.3, Kotlin 2.0.21).
